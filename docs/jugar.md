# Guía para jugadores

## Jugar por tu cuenta

1. Descarga [Luanti](https://www.luanti.org/en/downloads/) para tu sistema e instálalo. Es el cliente de este proyecto; el lanzador de Minecraft no sirve para unirse.
2. Dentro de Luanti, abre el navegador de contenido, busca **Mineclonia**, comprueba que aparece en **Juegos** e instálalo.
3. Selecciona Mineclonia y crea un mundo nuevo. Esta opción inicia tu propia partida, no una copia del Castillo.
4. Prueba lo básico: moverte con **WASD**, saltar con **Espacio** y abrir el inventario con **I**. Puedes cambiar las teclas en el menú.

## Entrar en un servidor

1. Pide al anfitrión la dirección, el puerto y la versión de cliente que recomienda.
2. Abre **Unirse a un juego** e introduce la dirección y el puerto. Si el anfitrión permite el alta, usa el registro del propio servidor. Si requiere invitación, sigue sus indicaciones.
3. Usa una contraseña exclusiva para ese servidor. Los mods del servidor se cargan al conectar; no hace falta instalar una copia local de cada mod.

El repositorio no incluye dirección de Jokxer-Luanti ni confirma la apertura del mundo. Para dudas del cliente, consulta la [guía oficial de inicio](https://docs.luanti.org/for-players/getting-started/).
