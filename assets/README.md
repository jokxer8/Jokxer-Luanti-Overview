# Imágenes del Castillo Jokxer

Material gráfico del recorrido público.

Los archivos con prefijo `captura-` muestran el mundo construido. Los archivos con prefijo `plano-` son ilustraciones de diseño; pueden incluir propuestas que no se construyeron.

| Archivo | Qué muestra |
| --- | --- |
| [Captura aérea](captura-aerea.webp) | Plaza, torres y acceso al recinto. |
| [Biblioteca](captura-biblioteca.webp) | Azotea ajardinada y balcones. |
| [Almacén Comunitario](captura-almacen.webp) | Interior y distribución de cofres. |
| [Sala de Trofeos](captura-trofeos.webp) | Vitrinas laterales y armaduras. |
| [Plano del castillo](plano-castillo.webp) | Diseño del recinto y de sus zonas. |
| [Plano de la biblioteca](plano-biblioteca.webp) | Propuesta de volumen, distribución y materiales. |
| [Banner](banner.svg) | Portada del repositorio. |
